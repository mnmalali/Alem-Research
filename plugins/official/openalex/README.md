# OpenAlex Academic Search

This official Alem provider maps the public OpenAlex Works API to the
`academic_search` capability. No API key is required. Supplying
`OPENALEX_MAILTO` is optional and supports OpenAlex's polite-pool guidance.

The plugin performs live network retrieval and marks results as retrieved
metadata, not independently verified full-text claims. OpenAlex API terms,
rate limits, and data licensing continue to apply.
