# Wenyu AI Research Skills Catalog

This is an offline, searchable catalog integration. It packages the catalog metadata, not the
separate plugin repositories or the `research-hub-pipeline` runtime. Results are discovery leads
and must not be treated as installed, verified, or executable capabilities.

Source: [WenyuChiou/ai-research-skills](https://github.com/WenyuChiou/ai-research-skills) at
commit `8547d889612ca624d523f39d20d35a97dbd87802`. The catalog license is retained in
`LICENSE-WENYU`. External repositories, Zotero, Obsidian, NotebookLM, and Hub credentials remain
separate integrations with their own approval and privacy review.
