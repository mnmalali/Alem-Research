# Orchestra Research Skills (curated)

This Alem plugin imports a small, reviewed subset of portable `SKILL.md` assets. It does not
run the upstream global installer and does not claim to import the full 98-skill library.

Source: [Orchestra-Research/AI-Research-SKILLs](https://github.com/Orchestra-Research/AI-Research-SKILLs)
at commit `773a52944ba4747a18bd4ae9ade53fff041adcbc` (`v1.7.2`). The copied assets retain
the upstream MIT license in `LICENSE-ORCHESTRA`. They are namespaced by Alem when adapters are
generated, so they do not overwrite canonical Alem skills.

The selected assets cover bounded autoresearch, research ideation, agent-native research
artifacts, and rigor review. They are instructions, not executable code or evidence sources.
Review them before enablement; Alem's plugin approval is not an OS sandbox.
