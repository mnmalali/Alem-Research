# Alem shared knowledge

This is the durable, Obsidian-compatible knowledge wiki. Start at [[index]]. Promote project findings only through [[../workflows/knowledge-update.yaml|the knowledge-update workflow]].

Pages use YAML frontmatter, stable IDs, wikilinks, and evidence references. Copy the appropriate `_template.md`; do not rename a stable page solely for style. Shared knowledge excludes secrets, copyrighted full texts, sensitive project data, and unsupported speculation presented as fact.
